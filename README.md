# 📌 Project 1 — Python Discount Calculator (Tkinter GUI)

## Description

The **Discount Calculator** is a desktop application built using **Python and Tkinter**.

The application provides a simple graphical user interface (GUI) where users can enter the original product price and discount percentage. The program then calculates and displays the final price after applying the discount.

---

## Features

* User-friendly graphical interface
* Calculate discounted prices automatically
* Support decimal price values
* Validate incorrect user input
* Display final price in Indonesian Rupiah (Rp)
* Simple and clean Tkinter layout

---

## Technologies Used

* Python 3
* Tkinter

---

## Calculation Formula

The application uses this formula:

$$Final Price = Original Price \times (1 - \frac{Discount}{100})$$

### Example:

* **Original Price:** Rp. 100000
* **Discount:** 20%

**Calculation:**

$$100000 \times (1 - \frac{20}{100})$$

* **Final Price:** Rp. 80000
